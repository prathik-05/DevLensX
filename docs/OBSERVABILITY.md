Events: analysis_started/completed, wiki/diagram generation, chat_started/completed, workspace impact/build/debug/review, incremental_started/completed, security_rejection (PATH_VIOLATION etc.). Metrics: parse/graph/wiki/diagram/chat/workspace/incremental durations + counts (files/symbols/relationships/pages/claims). Redaction: `OPENAI_API_KEY/Bearer/password/.env` → ***REDACTED***, source >500 chars with class → ***SOURCE_REDACTED***, no stack trace with source. Health: /api/health safe, /api/observability/metrics in-memory. Frontend: analysis_ready, wiki_opened, chat_started etc. with run_id/page/symbol, no source/secrets.
